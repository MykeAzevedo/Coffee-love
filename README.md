# ☕ CoffeeLove - Landing Page

Uma landing page moderna, elegante e totalmente responsiva desenvolvida para a cafeteria **CoffeeLove**. O projeto foi construído do zero com o objetivo de criar uma experiência visual atraente e fluida para o usuário, destacando o cardápio, a identidade visual da marca e facilitando a conversão de novos clientes.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as melhores práticas de desenvolvimento web semântico e estilização moderna:

*   **HTML5:** Estruturação semântica de tags (header, section, main, footer) garantindo melhor acessibilidade e SEO.
*   **CSS3:** Estilização avançada utilizando layouts modernos e flexíveis:
    *   **Flexbox & CSS Grid:** Para o alinhamento preciso dos elementos e componentes.
    *   **Responsividade:** Uso de *Media Queries* para garantir que a página fique impecável em smartphones, tablets e desktops.
    *   **Efeitos Visuais:** Backgrounds personalizados (como o fundo temático de grãos de café) e transições suaves de *hover* nos botões e cards.
*   **JavaScript (Vanilla):** Implementação de interações dinâmicas na interface, como o funcionamento do carrossel/slider, comportamento da barra de pesquisa e validações básicas.

---

## 🎨 Funcionalidades Principais

*   **Design Responsivo:** Adaptação perfeita a qualquer tamanho de tela.
*   **Seção Menu/Cardápio:** Exibição dos produtos através de componentes de cards limpos e modernos.
*   **Interatividade:** Componentes dinâmicos como carrossel de destaques e campo de busca funcional na interface.
*   **Clube CoffeeLove:** Seção de newsletter integrada para captura de leads e fidelização de clientes.
*   **Navegação Fluida:** Links internos com rolagem suave para melhorar a experiência do usuário.
